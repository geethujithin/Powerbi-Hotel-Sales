# Powerbi-Hotel-Sales
Restaurant Sales Analysis using Power BI is a data visualization and business intelligence project designed to analyze restaurant sales performance and customer behavior. The project uses a restaurant sales dataset containing information such as transaction details, order type, menu items, categories, restaurant locations, customer ratings, quantity, and revenue.

The data is analyzed and transformed using Microsoft Power BI to create an interactive dashboard. Key performance indicators such as Total Revenue, Total Orders, Total Quantity, Average Order Value, and Average Customer Rating are displayed to provide a quick overview of business performance.

The dashboard also provides detailed analysis of revenue trends over time, revenue by order type and category, customer ratings, restaurant locations, and menu-item performance. Interactive slicers and visualizations allow users to filter and explore the data from different perspectives.
Main Objectives
Analyze overall restaurant sales performance.
Track total revenue and number of orders.
Identify revenue trends across months and years.
Compare revenue between different order types and food categories.
Analyze customer ratings and their relationship with revenue.
Identify high-performing menu items.
Compare restaurant performance across different locations.
Create an interactive and easy-to-understand dashboard for decision-making.
Tools Used
Microsoft Power BI
Power Query – data cleaning and transformation
DAX – calculated measures and KPIs
Power BI Visualizations – charts, cards, slicers, etc.
